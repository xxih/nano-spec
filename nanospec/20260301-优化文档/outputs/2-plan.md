# 方案：文档体系优化与对齐执行

## 方案概述

本方案按“先纠偏、再实施”的顺序推进：先补齐流程产物并固化边界，再执行文档优化主线，确保每一步都有可追踪任务和可验收结果。

## 执行策略

1. 对齐修正
- 追加 `alignment.md`：记录输入缺失、范围边界和当前偏差。
- 同步 `outputs/1-spec.md`：补充执行边界与成功标志中的产物完整性要求。
- 补齐 `outputs/2-plan.md` 与 `outputs/3-tasks.md`，恢复流程完整性。

2. 文档主线实施（在当前边界内）
- README 主入口去重：消除重复章节，保留单一权威入口。
- guides 编排：将 `docs/` 调整为 `guides/`，明确每篇内部文档职责，并补充可达导航。
- 口径统一：对齐命令命名、阶段顺序、默认行为描述。
- 变更追踪：定义文档结构性变更与 `CHANGELOG.md` 的联动规则。

3. 验收与回写
- 基于 `1-spec.md` 验收标准逐项校验结果。
- 发现新偏差时追加 `alignment.md`，并同步更新 `3-tasks.md` 状态。
- 待出现新范围变更时，先写入 `alignment.md`，再回写 `1-spec.md` 与任务清单。

## 风险与应对

- 风险：内部文档目录改名后出现链接失效。
- 应对：同步修复 README 与索引中的路径引用，并做一次可达性自检。

- 风险：README 与 guides 在优化过程中再次出现口径分叉。
- 应对：以“单一权威位置”原则维护主题归属，重复信息仅保留引用链接。
