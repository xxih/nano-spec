# 验收

## 目标

生成或补齐 `outputs/acceptance.md`，把规格转化为可执行的验收用例。

## 输入

1. `outputs/1-spec.md`。
2. `outputs/2-plan.md`。
3. `alignment.md`（若存在）。
4. 已交付物与工作区现状。

## 执行流程

1. 覆盖每个核心需求，整理正常路径、异常路径和边界场景。
2. 将每个场景映射到具体的验证步骤、证据或预期结果。
3. 为失败、未覆盖或证据不足的场景补充后续动作。
4. 保存到 `outputs/acceptance.md`。

## 输出约束

- 每个需求至少对应一个验收场景。
- 验收步骤应可执行，结果应可判定。

## 规则

- 每个核心需求都必须有对应的验收覆盖。
- 对失败或证据不足的场景，补充明确的后续动作。
