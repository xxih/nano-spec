# 上手

## 目标

带新成员在真实仓库里走完一次最小可用的 NanoSpec 闭环，并解释每一步的意义。

## 输入

1. 用户附带的任务描述，或当前代码库里适合的新手任务。
2. 当前仓库是否已有 `.nanospec/` 与 `nanospec/`。

## 执行流程

1. 如果仓库未初始化，不要求先安装 CLI；直接创建最小目录结构或用脚本补齐任务骨架。
2. 选择一个能在单次会话内完成的小任务；若用户没给任务，可从代码库里推荐 3 到 4 个候选项。
3. 按 `YYYYMMDD-任务主题` 格式创建任务目录，并起草 `brief.md`。
4. 引导用户依次体验 spec -> align -> plan -> execute。
5. 用 accept 或 summary 收尾，再说明如何继续下一轮迭代。

## 规则

- 讲解必须基于当前仓库的真实文件和上下文。
- 控制范围，确保新手能在一轮里看到完整闭环。
- onboarding 的重点是教学，不是追求一次性做完大任务。
