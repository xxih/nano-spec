# 执行

## 目标

按 `outputs/3-tasks.md` 逐项交付，维护状态，并在发现偏差时及时对齐。

## 输入

1. `outputs/3-tasks.md`。
2. `outputs/1-spec.md`。
3. `outputs/2-plan.md`。
4. `alignment.md`（若存在）。
5. `outputs/acceptance.md`（若存在）。
6. 工作区相关文件。

## 执行流程

1. 读取 `3-tasks.md`，找到下一个未完成任务。
2. 按依赖关系执行任务。
3. 完成必要验证，并按验收条件确认结果。
4. 完成一个任务后立即将 `- [ ]` 更新为 `- [x]`。
5. 若发现偏差或阻塞，先追加到 `alignment.md`，再同步更新相关 outputs。
6. 重复直到所有任务完成或明确标注阻塞。

## 规则

- 复选框状态必须和实际进度同步更新。
- 遇到阻塞时，先把问题写入 `alignment.md`，再决定是否暂停。
- 变更需要同步到相关文档，不允许只改实现不改中间产物。
