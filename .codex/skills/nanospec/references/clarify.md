# 澄清

## 目标

扫描当前规格，识别模糊点并一次性输出到 `alignment.md` 供用户确认。

## 输入

1. `outputs/1-spec.md`。
2. `brief.md` / `prd.md`。
3. `assets/*`。
4. `alignment.md`（若存在）。

## 执行流程

1. 扫描规格覆盖度，重点检查：功能范围、数据模型、交互流程、非功能要求、边界情况、术语一致性。
2. 将发现的问题按影响力排序，控制在最多 5 个。
3. 对每个问题给出推荐答案或建议。
4. 将问题一次性追加到 `alignment.md`，并使用 `[歧义]` 或其他合适标签，加上 `` `⏳ 待确认` ``。
5. 用户确认后，移除待确认标记，并同步回 `1-spec.md` 或其他受影响产物。

## 输出约束

- 问题应一次性输出到 `alignment.md`，而不是零散追问。
- 只问会影响规格、计划、任务拆分或验收的问题。

## 规则

- 先问最少但真正阻塞推进的问题。
- 每个问题都要带推荐答案或建议。
- 已确认结论必须落盘，不能只留在对话里。
