# 总结

## 目标

输出 `outputs/summary.md`，沉淀可复用经验、关键决策和剩余风险。

## 输入

1. `alignment.md`。
2. `outputs/1-spec.md`。
3. `outputs/2-plan.md`。
4. `outputs/3-tasks.md`。
5. `outputs/acceptance.md`（若存在）。
6. 已交付物与工作区现状。

## 执行流程

1. 从 `alignment.md` 提取已解决的关键决策。
2. 总结已交付范围、验证证据和实际结果。
3. 识别反复出现的偏差、冲突或教训。
4. 提炼可复用的 checklist 或操作建议。
5. 记录剩余风险、未完事项和后续建议。

## 规则

- 不要声明任务结果里没有体现的工作。
- 未解决事项必须写得明确且可执行。
- 总结应能直接用于交接和下次复用。
