# NanoSpec Summary

## Objective

Generate `outputs/summary.md` that captures what was delivered and why.

## Steps

1. Read `brief.md`, `alignment.md`, `outputs/1-spec.md`, `outputs/2-plan.md`, `outputs/3-tasks.md`, and `outputs/acceptance.md` (if present).
2. Summarize completed scope, key design decisions, and deviations.
3. Include validation evidence (tests, checks, acceptance status).
4. Record residual risks, deferred items, and recommended next actions.
5. Save concise final summary for handoff.

## Rules

- Do not invent completed work not reflected in tasks/results.
- Keep unresolved items explicit and actionable.
- Preserve task language/style unless user requests rewrite.
