# NanoSpec Onboard

## Objective

Guide a newcomer through one complete NanoSpec cycle in a real repository.

## Steps

1. Verify prerequisites (`nanospec --version`, initialization status).
2. Help user choose a small, realistic starter task.
3. Execute CLI setup actions (`nanospec new ...`) and draft `brief.md`.
4. Guide user through spec -> align -> plan -> execute commands with explanation at each step.
5. Finish with recap, command cheatsheet, and continuation guidance.

## Rules

- Prefer teaching through real repository context, not abstract demos.
- Keep scope small enough to complete in one onboarding session.
- Emphasize that align can be used at any phase for continuous correction.
